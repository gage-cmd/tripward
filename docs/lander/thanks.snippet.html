You’re in. There is no license key.

Stripe collected payment. Protection is local. Clone, init into a throwaway repo, then doctor and run. Same steps: docs/SETUP.md.

1. Clone

git clone https://github.com/gage-cmd/fusecap.git tripward
cd tripward
git checkout main
npm install

2. Init into a throwaway repo

Not the only copy of work you care about. The path after npx tsx is this clone.

cd /path/to/your-throwaway-repo

npx tsx /path/to/tripward/src/cli.ts init --preview
npx tsx /path/to/tripward/src/cli.ts init

3. Doctor

npx tsx /path/to/tripward/src/cli.ts doctor

Read OVERALL and every FAIL row. Claude Code missing is an honest degrade — not a license problem.

4. Run (Claude Code required for a real session)

claude --version
npx tsx /path/to/tripward/src/cli.ts run
# small real task, then quit normally

Without claude on PATH, the CLI uses the documented stub and the receipt says so.

5. Receipt and restore preview

npx tsx /path/to/tripward/src/cli.ts receipt --html
npx tsx /path/to/tripward/src/cli.ts restore --preview --html

Open the printed HTML. The recovery page does not apply. Never git reset --hard.
